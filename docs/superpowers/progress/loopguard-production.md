- Last completed step: `CLOUD-T06` completed inline. The cloud creates a short-lived reviewed challenge that binds schema/canonicalization version, action/target/host, parameter hash, expected state version/hash, tenant, user, selected device, issuance/expiry, and nonce in deterministic UTF-8 JSON. A current tenant/user/device Ed25519 key must sign those bytes before an externally injected cloud signer countersigns and the API returns only `202 queued`; only host resolution sets executed/rejected. The daemon independently verifies both signatures and current key states, tenant/host binding, expiry, nonce, expected state, capability policy, and unique action ID under one lock. Device revocation rejects reviewed work and revokes queued unconsumed actions; unknown/revoked keys fail closed.
